## 8. App Store Review Notes

```
Dear App Review Team,

Thank you for reviewing Cosmo Trader.

WHAT THIS APP IS:
Cosmo Trader is an entertainment/lifestyle app with a stock portfolio tracking feature. It combines real stock market data with astrological/zodiac themes for entertainment purposes.

IMPORTANT CLARIFICATIONS:

1. NOT FINANCIAL ADVICE
This app is explicitly NOT a financial advisory service. We display multiple disclaimers throughout the app stating that:
- Content is for entertainment only
- Users should consult qualified financial advisors
- Astrological content has no scientific basis for predicting markets

2. NO TRADING FUNCTIONALITY
The app does NOT connect to brokerages, execute trades, or handle any real money transactions (except optional subscription via StoreKit). It is purely a tracker and entertainment platform.

3. DATA SOURCE
Stock market data is provided by Finnhub.io API with proper attribution displayed in the app. Data may be delayed up to 15 minutes.

4. ASTROLOGICAL CONTENT
All zodiac/horoscope content is presented as entertainment. We never claim it can predict stock performance. The app frequently makes self-aware jokes about this (e.g., "Does the moon affect markets? Science says no. But we track it anyway.")

5. SUBSCRIPTION (Oracle Tier)
- $4.99/month with 7-day free trial
- Implemented via StoreKit 2

- Easy cancellation via iOS settings

TEST ACCOUNT:
No account required. The app works immediately upon launch. Onboarding asks for birth date (for zodiac calculation only, stored locally).

KEY SCREENS TO REVIEW:
- Profile > Not Financial Advice (full disclaimer)
- Profile > About Cosmo Trader (attribution)
- Any horoscope/compatibility screen (entertainment disclaimers)

We're happy to answer any questions or make adjustments if needed.

Thank you for your time!
```
